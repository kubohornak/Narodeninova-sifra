NARODENINOVÁ ŠIFROVAČKA – VERZIA 2

UPRAVUJ HLAVNE config.js.
Pri každej šifre vieš zmeniť image, password a hint.

Príklad:
{ image: "images/sifra1.jpg", password: "bratislava", hint: "Pozri sa na čísla ako na písmená abecedy." }

NOVÉ:
- tlačidlo i s vlastnou nápovedou pri každej šifre,
- progres sa automaticky ukladá v prehliadači,
- po 10. hesle sa zobrazí poukážka,
- tlačidlo Stiahnuť poukážku.

Obrázky vlož do images a názov zmeň v config.js.
GitHub Pages: nahraj všetky súbory do public repository → Settings → Pages → Deploy from a branch → main → / → Save.
